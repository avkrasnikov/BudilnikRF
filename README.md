Android-приложение на Kotlin + Jetpack Compose: будильник, который умеет не срабатывать в государственные праздники, выходные и переносы, а также не будить вас в отпуске. Производственный календарь РФ загружается с общедоступного API [isdayoff.ru](https://isdayoff.ru) и кэшируется на устройстве. Мелодию можно выбрать из аудиофайлов на телефоне.

Проект готов к сборке и установке. Исходники находятся в этой папке, подписанные APK — в `dist/`.

## Что уже реализовано

- Список будильников, включение/выключение, удаление.
- Создание и редактирование будильника: время, название, дни повтора, вибрация, интервал отложения.
- Чекбокс **«Не срабатывать в государственные праздники»** — по производственному календарю РФ, включая выходные и переносы.
- Период отпуска: два поля с календарём (начало и окончание). Внутри периода будильник не срабатывает.
- Загрузка календаря по HTTPS с isdayoff.ru, кэш на 24 часа и офлайн-фолбэк (выходные + федеральные праздники).
- Экран нерабочих дней с названиями праздников, переносами и количеством дней по месяцам.
- Выбор мелодии из файлов устройства через системный файловый менеджер (SAF). Файл копируется во внутреннее хранилище приложения, поэтому не зависит от выданных разрешений.
- Точные будильники через `AlarmManager.setAlarmClock()`, foreground-сервис со звуком и вибрацией, полноэкранный экран будильника поверх блокировки.
- Кнопки «Выключить» и «Отложить», автопрекращение сигнала через 10 минут.
- Восстановление расписания после перезагрузки, смены времени и часового пояса.
- Экран настроек с проверкой разрешений и тестовым будильником через 10 секунд.
- Подсказки для Xiaomi/Redmi/POCO: автозапуск, ограничения батареи, полноэкранные уведомления.

## Готовые артефакты

| Файл | Назначение |
|---|---|
| `dist/BudilnikRF-1.0.0.apk` | Подписанный release APK для установки на устройство |

Параметры сборки:

- `applicationId`: `ru.holidayalarm`
- версия: `1.0.0` (`versionCode = 1`)
- `minSdk = 26` (Android 8.0)
- `compileSdk = 36`, `targetSdk = 36`
- подпись: APK Signature Scheme v2, ключ 4096-bit RSA
- release: R8 + shrinkResources


### Без ADB

Скопируйте APK на телефон (USB/облако), откройте файл, разрешите установку из этого источника. Play Protect может предупредить — это нормально для APK вне магазина.

### Обязательные настройки HyperOS

1. **Автозапуск**: Настройки → Приложения → Управление приложениями → Будильник РФ → Автозапуск.
2. **Батарея**: там же → Батарея → **Без ограничений**.
3. **Уведомления**: разрешить, включить «Показывать на экране блокировки».
4. **Точные будильники**: Настройки → Приложения → Специальные возможности → Будильники и напоминания → разрешить.
5. **Полноэкранные уведомления** (Android 14+): Настройки → Приложения → Специальные возможности → Полноэкранные уведомления → разрешить.
6. В приложении откройте **Настройки → Проверка → Проверить через 10 секунд** и убедитесь, что экран и звук сработали при заблокированном телефоне.

Если будильник не срабатывает, см. `docs/05-XIAOMI.md`.

## Как это работает

### Календарь

Запрос:

```text
https://isdayoff.ru/api/getdata?year=2026&cc=ru
```

Ответ — строка из 365/366 символов:

| Код | Значение |
|---|---|
| `0` | рабочий день |
| `1` | нерабочий день (праздник, выходной, перенос) |
| `2` | сокращённый рабочий день |
| `4` | рабочий день (особый случай) |

Приложение кэширует строки по годам в `SharedPreferences` и обновляет их не чаще раза в 24 часа. Если сети нет, используется офлайн-фолбэк: суббота, воскресенье и фиксированные федеральные праздники. Это гарантирует, что будильник не «замолчит» навсегда из-за недоступности API.

### Планирование

Для каждого будильника вычисляется ближайшее разрешённое срабатывание:

1. Берётся текущее время в локальной зоне.
2. Кандидат — сегодня в заданное время; если время прошло — завтра.
3. Проверяются дни повтора (если выбраны).
4. Проверяется период отпуска.
5. Если включён чекбокс, проверяется производственный календарь: день с кодом `1` пропускается.
6. Поиск ограничен 800 днями, чтобы не зациклиться.

Повторяющийся будильник после срабатывания планируется на следующую допустимую дату. Одноразовый — выключается. «Отложить» создаёт отдельный точный триггер на 5–20 минут.

## Ограничения

- iPhone/iOS не реализованы — по условию задачи.
- Приложение зависит от доступности isdayoff.ru; при отсутствии сети работает офлайн-фолбэк.
- На некоторых прошивках (особенно Xiaomi/HyperOS) требуется ручная настройка автозапуска и батареи — это ограничение ОС, а не приложения.
- Календарь обновляется при запуске приложения и вручную; отдельного фонового планировщика синхронизации нет.
- Тексты интерфейса — на русском языке.

## Конфиденциальность

Приложение не собирает аналитику и не отправляет персональные данные. Наружу уходит только запрос производственного календаря на isdayoff.ru без идентификаторов пользователя. Будильники, настройки и выбранные мелодии хранятся только на устройстве. Подробнее — `PRIVACY.md`.
