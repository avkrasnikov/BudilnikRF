# Настройка Xiaomi 15T Pro (HyperOS)

Xiaomi/HyperOS агрессивно управляет фоновыми приложениями. Чтобы будильник срабатывал стабильно, приложению нужны несколько разрешений помимо стандартных Android. Ниже — что включить и как проверить.

## 1. Установка

### Через ADB

На телефоне:

1. Настройки → О телефоне → нажимайте «Версия HyperOS» 7 раз.
2. Настройки → Дополнительные настройки → Для разработчиков.
3. Включите «Отладка по USB».
4. Подключите USB, выберите режим «Передача файлов», подтвердите отпечаток компьютера.

На компьютере:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" devices -l
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r "C:\git\oms\holiday-alarm\dist\BudilnikRF-1.0.0.apk"
```

Если `adb devices` показывает `unauthorized` — разблокируйте телефон и подтвердите запрос.

### Без ADB

Скопируйте APK на телефон, откройте через «Проводник», разрешите установку из этого источника. Play Protect может показать предупреждение — это ожидаемо для APK вне магазина.

## 2. Обязательные настройки HyperOS

Пути могут немного отличаться в зависимости от версии HyperOS. Ищите по названиям.

### 2.1. Автозапуск

**Настройки → Приложения → Управление приложениями → Будильник РФ → Автозапуск** — включить.

Это нужно, чтобы после перезагрузки `BootReceiver` получил `BOOT_COMPLETED` и восстановил расписание.

### 2.2. Батарея без ограничений

Там же: **Будильник РФ → Батарея → Без ограничений** (или «Нет ограничений»).

Дополнительно:

**Настройки → Батарея → Экономия энергии** — убедитесь, что для будильника нет ограничений.

Если доступен режим «Спящий режим»/«Ultra battery saver», добавьте приложение в исключения.

### 2.3. Уведомления

**Настройки → Приложения → Будильник РФ → Уведомления**:

- разрешить уведомления;
- важность — высокая;
- «Показывать на экране блокировки» — включить;
- «Показывать баннер» — включить;
- звук уведомления можно оставить системным/без звука: звук будильника играет сервис.

### 2.4. Точные будильники

**Настройки → Приложения → Специальные возможности → Будильники и напоминания → Будильник РФ** — разрешить.

На Android 13+ приложение с `USE_EXACT_ALARM` обычно получает это автоматически, но HyperOS может показывать отдельный переключатель.

### 2.5. Полноэкранные уведомления (Android 14+)

**Настройки → Приложения → Специальные возможности → Полноэкранные уведомления → Будильник РФ** — разрешить.

Без этого экран будильника может не появиться поверх блокировки; останется только уведомление.

### 2.6. Другие ограничения

Проверьте:

- **Настройки → Приложения → Будильник РФ → Другие разрешения** — не должно быть запретов.
- **Настройки → Конфиденциальность → Специальные разрешения** — приложение не должно быть ограничено.
- Если включён «Режим экономии», добавьте будильник в исключения.

## 3. Проверка

1. Откройте приложение.
2. Настройки → Проверка → **Проверить через 10 секунд**.
3. Заблокируйте экран.
4. Должны появиться экран будильника, звук и вибрация.
5. Нажмите «Выключить».
6. Повторите, нажмите «Отложить» — сигнал должен повториться через выбранный интервал.

Проверка восстановления после перезагрузки:

1. Создайте будильник на 3–5 минут вперёд.
2. Перезагрузите телефон.
3. Не открывая приложение, дождитесь сигнала.

Проверка праздников:

1. Откройте «Календарь» и найдите ближайший нерабочий день.
2. Создайте будильник на этот день с включённым чекбоксом.
3. Убедитесь, что карточка показывает следующую рабочую дату.

Проверка отпуска:

1. Включите «Не будить в отпуске».
2. Поставьте период, включающий завтра.
3. Будильник на завтра не должен сработать; следующая дата — после отпуска.

## 4. Диагностика через ADB

Проверить, что будильник зарегистрирован:

```powershell
adb shell dumpsys alarm | Select-String "ru.holidayalarm"
```

Проверить разрешения:

```powershell
adb shell dumpsys package ru.holidayalarm | Select-String "POST_NOTIFICATIONS|SCHEDULE_EXACT_ALARM|USE_EXACT_ALARM|USE_FULL_SCREEN_INTENT"
```

Проверить, что сервис запускался:

```powershell
adb logcat -d -s AlarmScheduler AlarmService AlarmReceiver | Select-Object -Last 100
```

Проверить батарейную оптимизацию:

```powershell
adb shell dumpsys deviceidle whitelist | Select-String "ru.holidayalarm"
```

Если приложение в whitelist — ограничения сняты.

## 5. Частые проблемы

### Будильник не срабатывает после перезагрузки

- не включён автозапуск;
- HyperOS не отдала `BOOT_COMPLETED`;
- приложение было «заморожено» после очистки памяти.

Решение: автозапуск + «Без ограничений», затем перезагрузить и проверить.

### Будильник срабатывает с опозданием

- нет разрешения на точные будильники;
- включён жёсткий режим экономии;
- приложение ограничено в фоне.

Проверьте баннер в приложении и настройки батареи.

### Нет экрана поверх блокировки

- не разрешены полноэкранные уведомления (Android 14+);
- канал уведомлений понижен до «Тихий»;
- на экране блокировки запрещены уведомления приложения.

Проверьте важность канала и разрешение на экран блокировки.

### Нет звука

- громкость «Будильники» на телефоне равна 0;
- выбранный файл повреждён/удалён — приложение откатится на системный будильник;
- включён беззвучный режим с запретом будильников (некоторые прошивки).

Проверьте громкость будильника и выберите мелодию заново.

### Будильник сработал в праздник

- календарь не обновлён (нет интернета и кэш устарел);
- чекбокс выключен;
- это перенесённый рабочий день, а не выходной — проверьте календарь.

Откройте приложение и нажмите «Обновить календарь».

### Приложение удаляется из памяти

HyperOS может выгружать приложение. Для будильника это не критично, если сработал `AlarmManager`: receiver и foreground-сервис поднимутся. Но автозапуск и батарея всё равно нужны.

## 6. После обновления приложения

Обновление APK поверх установленного сохраняет данные. Если вы меняли package name — это уже другое приложение, будильники не перенесутся. При обновлении HyperOS иногда сбрасывает разрешения — проверьте их снова через экран настроек приложения.

## 7. Что не надо делать

- Не «оптимизируйте» приложение через сторонние чистильщики памяти.
- Не отключайте уведомления полностью — пропадёт экран будильника.
- Не включайте «Не беспокоить» с запретом будильников, если ждёте сигнал.
- Не используйте режим «Ultra battery saver» без добавления будильника в исключения.
