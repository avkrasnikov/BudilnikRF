# Описание приложения «Будильник РФ»

## Короткое описание (для карточки магазина)

**Будильник, который знает праздники и ваш отпуск.**

Варианты:

- «Будильник РФ — не будит в праздники, выходные и отпуск.»
- «Умный будильник с производственным календарём России.»
- «Будильник, который уважает ваши выходные.»

## Полное описание

«Будильник РФ» — простой и надёжный будильник для Android, который учитывает государственные праздники, выходные и переносы дней, а также период отпуска.

Больше не нужно вручную отключать будильник перед длинными выходными или вспоминать, что завтра праздник. Приложение загружает производственный календарь России с общедоступного API isdayoff.ru и само переносит сигнал на следующий рабочий день.

### Возможности

- **Праздники и выходные.** Включите чекбокс «Не срабатывать в государственные праздники» — будильник пропустит нерабочие дни по производственному календарю РФ, включая выходные и переносы.
- **Отпуск.** Укажите период двумя датами — в это время будильник не побеспокоит.
- **Гибкий повтор.** Выберите дни недели, будни, выходные или «каждый день».
- **Своя мелодия.** Выберите любой аудиофайл из памяти телефона. Приложение сохранит копию, поэтому мелодия продолжит работать после перезагрузки.
- **Точное срабатывание.** Используются системные точные будильники, поэтому сигнал срабатывает в заданное время даже в режиме энергосбережения.
- **Экран поверх блокировки.** Крупное время, название будильника, кнопки «Выключить» и «Отложить».
- **Отложить.** Настройте интервал 5, 10, 15 или 20 минут.
- **Вибрация.** Отдельное включение/выключение.
- **Календарь нерабочих дней.** Посмотрите праздники и переносы по месяцам.
- **Работа офлайн.** Календарь кэшируется; при отсутствии интернета используются выходные и федеральные праздники.
- **Проверка настроек.** Тестовый будильник через 10 секунд и статусы разрешений.
- **Поддержка Xiaomi/HyperOS.** Подсказки по автозапуску и ограничениям батареи.

### Для кого

- для офисных сотрудников с графиком 5/2;
- для тех, кто часто просыпается в праздники;
- для планирования отпуска и длинных выходных;
- для всех, кто хочет, чтобы будильник уважал календарь.

### Конфиденциальность

Приложение не собирает аналитику и не отправляет персональные данные. Наружу уходит только запрос производственного календаря на isdayoff.ru без идентификаторов пользователя. Будильники, настройки и мелодии хранятся только на устройстве.

### Технические детали

- Android 8.0+ (API 26+);
- целевая версия Android 16 (API 36);
- Kotlin, Jetpack Compose, Material 3;
- точные будильники `AlarmManager.setAlarmClock`;
- foreground-сервис для звука;
- выбор файла через системный SAF без доступа ко всей медиатеке.
