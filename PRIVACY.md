# Политика конфиденциальности приложения «Будильник РФ»

Дата вступления в силу: 4 ноября 2026 г.

## 1. Общие положения

Настоящая политика описывает, какие данные обрабатывает приложение «Будильник РФ» (далее — Приложение), как они хранятся и передаются.

Приложение предназначено для работы на устройствах Android. Оно не требует регистрации, не содержит рекламы и не использует аналитические или трекинговые SDK.

## 2. Какие данные обрабатываются

Приложение хранит **только на устройстве**:

- время, дни повтора и настройки будильников;
- названия будильников;
- периоды отсутствия (отпуск, декрет, нерабочий день, отгул);
- выбранный регион и ручные региональные/муниципальные даты с описанием;
- даты и описания, импортированные из выбранных пользователем ICS-файлов;
- даты-исключения «разбудить в нерабочий день»;
- выбранные мелодии (копии аудиофайлов в приватном хранилище Приложения);
- кэш производственного календаря РФ;
- служебные настройки (например, выбранный интервал отложения).

Приложение **не собирает**:

- имя, телефон, email;
- геолокацию;
- контакты;
- историю звонков и SMS;
- фотографии и видео;
- рекламные идентификаторы;
- данные о других приложениях;
- аналитику использования.

## 3. Сетевые запросы

Приложение загружает производственный календарь РФ с общедоступного API:

```text
https://isdayoff.ru/api/getdata?year=YYYY&cc=ru
```

В запросе передаются только год и код страны. Приложение не передаёт идентификаторы пользователя, cookies, токены или сведения об устройстве. Соединение защищено HTTPS.

Сервер isdayoff.ru может обрабатывать технические данные (IP-адрес, user-agent) в соответствии со своей политикой. Приложение не контролирует обработку данных на стороне этого сервиса.

Если интернет недоступен, Приложение использует локальный кэш и офлайн-набор выходных/федеральных праздников. Никакие данные при этом не отправляются.

ICS-файлы, выбранные пользователем для импорта отпуска, региональных дат или исключений, читаются только на устройстве. Приложение не копирует и не отправляет их в сеть; сохраняются только извлечённые даты и описания.

## 4. Разрешения и зачем они нужны

| Разрешение | Назначение |
|---|---|
| `INTERNET` | загрузка производственного календаря |
| `POST_NOTIFICATIONS` | уведомление и экран будильника |
| `SCHEDULE_EXACT_ALARM`, `USE_EXACT_ALARM` | точное срабатывание в заданное время |
| `RECEIVE_BOOT_COMPLETED` | восстановление будильников после перезагрузки |
| `WAKE_LOCK` | работа сигнала при заблокированном экране |
| `VIBRATE` | вибрация будильника |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | проигрывание мелодии будильника |
| `USE_FULL_SCREEN_INTENT` | показ экрана будильника поверх блокировки |

Доступ к медиатеке (`READ_MEDIA_AUDIO`) **не запрашивается**. Мелодия выбирается пользователем через системный диалог открытия файла; Приложение получает доступ только к выбранному файлу и сохраняет его копию в своём приватном хранилище.

## 5. Передача данных третьим лицам

Приложение не продаёт, не передаёт и не раскрывает персональные данные третьим лицам. Единственный внешний запрос — загрузка календаря с isdayoff.ru, описанная в разделе 3.

## 6. Хранение и удаление

Данные хранятся на устройстве в приватном хранилище Приложения и удаляются вместе с Приложением. Отдельные будильники и выбранные мелодии можно удалить в интерфейсе Приложения.

Резервное копирование данных Приложения отключено (`allowBackup=false`), чтобы расписание не переносилось на другое устройство в неверном виде.
